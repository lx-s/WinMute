# How To Contribute

## New Features

If you have the next great idea for this little tool, you are welcome to open an
issue with your idea. This is how WiFi- and Bluetooth-based muting came to life 🙂

If your idea is too big for the scope of this tool or I don't have the time to
implement it, I'll let you know and you are free to open a PR yourself, if you
have the time and resources.

## Bug Fixes

You're welcome at any time to provide pull requests with fixes for bugs you discovered.
I will not look through large swathes of code though, so try to keep your PR as small
and focused as possible. If it is mostly AI generated code I ask you to be open about
it up-front. Try to keep it in the current coding style as much as possible — the
repository ships a `.clang-format` and an `.editorconfig`, which should cover most of
it. Apart from that I won't dictate any strict rules.

## Art

Since my artistic competence is hovering right around the skill level of "programmer art",
a new program icon suitable for Windows' light and dark themes (or GitHub's README) would be greatly appreciated 🙂

## Translations

You are invited to provide translations for the app. But there are some rules.

1. Please only translate if you are fluent in the language you are translating into and if you are familiar with the nomenclature of the Windows system. If in doubt about a specific string, check out other Windows apps you like to use and see how they did it.
2. Only contribute if you are committed to translating the majority of strings. No one wants an app that is a mix of mostly English and very little of the native language. I might remove translations again if they don't receive updates for new string resources.

[![Translation Status](https://translate.codeberg.org/widget/winmute/winmute/multi-auto.svg)](https://translate.codeberg.org/engage/winmute/)

Translations can be provided via [Weblate](https://translate.codeberg.org/engage/winmute/).
